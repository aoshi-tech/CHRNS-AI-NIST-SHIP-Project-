# Neutron Scattering Lengths and Cross Sections

This resource provides thermal neutron scattering lengths and cross sections for elements and their isotopes.

## Data Scope and Limitations

*   **Energy Range**: The provided values are **thermal neutron cross sections only**. Energy-dependent cross sections are not available here. For energy-dependent data, refer to the [National Nuclear Data Center at Brookhaven National Lab](https://www.nndc.bnl.gov/).
*   **Elemental Range**: Data is provided for elements up to atomic number 96 (Cm - Curium).
*   **Data Entry**: These data were entered by hand and may contain errors.

## Source Attribution

All data is sourced from:
*   *Neutron News*, Vol. 3, No. 3, 1992, pp. 29-37, "Special Feature section of neutron scattering lengths and cross sections of the elements and their isotopes."
